# javascript-2-assignment

How to use the site:

1) create user or login to an existing account
    NOTE: The email must contain "@stud.noroff.no"
    EXAMPLE: Steinar@stud.noroff.no

2) browse on the feed page. see all kind of posts available
    - On each post you can click on the username (author) and you'll be sent to their profile page
    - click on the post to see the full post (comments and reactions are now available, but it is a counter there) on a single post page.

3) See other profile (se step 2 to navigate to a user profile)
    - see posts created by them
    - follow/infollow the users

4) My profile page
    - Access your own profile page and see your own posts.
    - create new posts with a click on a button
    - delete or edit posts with a click on a button
    - edit profile with a click on a button.
    - click on post image to see the post on a single page

5) create post
    - Title is required.
    - add an image (optional)
    - add description/body text (optional)
    - add an image alt (describe the picture in case the image won't show)

6) edit profile
    - change the banner url
    - change the avatar url
    - change bio text

7) Settings
    - log out
    - see terms of use
    - see privacy policy
    - edit profile

8) search results (only accessable through search bar)
    - get sent to a single page where your search results is displayed (in progress now)

9) contact page (only for styiling but a "message sent" alert will appear)
